# 2026-11-18 SmartWardrobe 智能电子衣橱

## 项目概况
从零构建原生 Android App，路径 E:/agent_xiangmu/workbuddy/dianziyichu。
Kotlin 2.0.21 + Compose Material3 + MVVM/Clean Architecture + Hilt + Room + DataStore + Retrofit + Coil3 + ML Kit。

## 环境（全部内置项目目录，不污染系统）
- JDK Temurin 17.0.21: .toolchain/jdk/jdk-17.0.21+9
- Gradle 8.9: .toolchain/gradle/gradle-8.9（gradlew 已指向本地 zip）
- Android SDK 34+35: .toolchain/android-sdk
- 编译命令: env.bat 后 gradle :app:compileDebugKotlin --no-daemon

## 关键版本坑（已解决）
- Room 必须 2.7.2（2.6.1 不支持 KSP2）
- core-ktx 1.15.0 要求 compileSdk>=35
- camera-compose 1.3.4 不存在（Phase4 需要时用更高版本）
- ML Kit Subject Segmentation 正确 API: SubjectSegmenterOptions.Builder().enableForegroundBitmap() + result.getForegroundBitmap()（不是 SubjectSegmentationOptions）
- Retrofit kotlinx converter 包名: com.jakewharton.retrofit2.converter.kotlinx.serialization.asConverterFactory
